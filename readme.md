# SnapMem

**SnapMem** is a privacy-first, offline tool to extract and organize Snapchat Memories  
from the official Snapchat data export (JSON).

No uploads. No servers. Your data stays local.

---

## Why SnapMem?

Snapchat exports memories as raw JSON files that are hard to use without technical knowledge.
SnapMem turns this export into a clean, human-readable media archive.

---

## Key Features

- Extract images and videos from Snapchat JSON exports
- Structured output by date (YYYY/MM/DD)
- Offline-only, privacy-first
- Core engine independent from UI
- CLI tool (Desktop app planned)
